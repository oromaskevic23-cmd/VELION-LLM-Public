Version locked to **soup-cli 0.77.0** (PyPI release 26 Oct 2026).

## Actual commands (operator-controlled host, Windows / Linux / macOS)

Use **Python 3.11, 3.12 or 3.13**. From repository root:

```sh
python training/soup/soup_lab.py status
python training/soup/soup_lab.py install --mode core
python training/soup/soup_lab.py doctor
```

CLI-only installation uses the official PyPI distribution and does not install
PyTorch, fetch model weights, start a service, train or upload any data.
All packages are kept in `training/soup/.venv` and ignored by git.
The pinned root requirement does **not** lock all transitive dependencies;
add a reviewed wheel hash/lockfile before using this as a production release.

For a **separately approved local training pilot**, after confirming host,
ownership of datasets, licenses, disk space, GPU compute capability and
preflight, an operator may explicitly execute:

```sh
python training/soup/soup_lab.py install --mode train --allow-heavy-install
python training/soup/soup_lab.py doctor
```

Then create a **private, ignored** working directory for synthetic or
licensed records; use the CLI to create a fresh code template, rather than
reusing an older schema (Soup 0.77 refuses some obsolete keys):

```sh
# From a private working directory outside Git, using the locally installed CLI:
path/to/VELION-LLM-Public/training/soup/.venv/bin/soup init --template code
path/to/VELION-LLM-Public/training/soup/.venv/bin/soup doctor --config soup.yaml
```

On Windows use `training\soup\.venv\Scripts\soup.exe` in place of
`training/soup/.venv/bin/soup`. This document deliberately does **not**
include an automatic `soup train` action. A config generated by Soup must
be independently reviewed: base-model license, immutable owner eval set,
private training-data rights, QLoRA compatibility, batch-size and VRAM,
network/data-flow boundary, and resource budget.

**GPU caution:** 7B-class QLoRA may need 8GB+ VRAM and layer streaming is beta.
The project's reported memory benchmarks are not a successful local
RTX 2070 SUPER or GitHub-hosted GPU test. GitHub's free Ubuntu CI runners are
used only to install the *light CLI*; they do not verify training capability.

## Acceptance gates for a future VELION adapter

1. Baseline and LoRA-adapted candidate are compared on identical *held-out*
   code quality, safety, latency and memory benchmarks; no invented PASS.
2. The base model's license and any redistribution rights are documented.
3. Generated weights, private datasets and personally identifiable data remain
   outside the public repository and public CI artifacts.
4. All releases require owner approval through the applicable Guardian /
   Approval Gateway process, independent QA and an evidence manifest.
5. Rollback keeps the current Nemotron 3 local signed bridge unchanged.
6. Never claim proprietary base weights, perpetual inference, 24/7 NCA,
   verified revenue or commercial production from a CLI installation.
