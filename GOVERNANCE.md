# Governance

This repository documents governance expectations for the VELION project. Governance is layered and separates authority from identity and capability.

Canonical roles

- Architect: Alexander Romaskevich (final architectural decision authority)
- HANTER: Chief Systems — AI Command Center / Deputy to the Architect (advisory / operational deputy role)

Governance flow (public):

- Architect → HANTER → Federated Multi-Orchestrator Layer → Runtime Domains → governed agents/tools

Canonical security laws (public):

- Identity != Authority
- Capability != Approval
- Intelligence != Privilege

Default access model: DENY BY DEFAULT
