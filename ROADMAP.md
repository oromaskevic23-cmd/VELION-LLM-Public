# Roadmap

This file lists high-level milestones for the public VELION project.

- Bootstrap public engineering baseline (completed in bootstrap PR)
- Public architecture publication
- Memory bootstrap specifications
- Minimal runtime orchestration prototypes
- Public telemetry and evaluation harness (non-production)

Scale roadmap (evidence-gated gates)

- GATE S3: Verified 1,000-NCA fleet control — requires evidence and verification before advancing
- GATE S4: 10,000-NCA simulation → controlled deployment → evidence
- GATE S5: 100,000-NCA simulation → distributed stress testing → controlled deployment → evidence
- GATE S6: 1,000,000-NCA simulation → infrastructure qualification → security qualification → economic feasibility → evidence

Status of items will be tracked with the repository status tags and gate evidence checklist.
