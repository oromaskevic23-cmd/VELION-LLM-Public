# Contributing

Thank you for contributing. Please read the CODE_OF_CONDUCT.md and CONTRIBUTING.md before filing issues or PRs.

Key points:

- Follow the Authorship & Attribution rules in AUTHORSHIP.md.
- Avoid committing secrets, credentials, or private data.
- Use the repository's status tags (PLANNED, SPECIFIED, IMPLEMENTED, TESTED, DEPLOYED, LIVE_VERIFIED, NOT_VERIFIED, BLOCKED) for progress tracking in documentation.
