## Publish first, index second

1. Confirm a real HTTPS public project page, its exact final canonical URL and HTTP 200 status; create clear human-visible descriptions and research limitations.
2. Make each project page link back to the founder and to its corresponding public source. Use a consistent signature and project identity without keyword stuffing.
3. Add accurate title, meta description, language, accessible navigation and JSON-LD that mirrors visible content.
4. Use `Person` for an actual founder profile; `SoftwareSourceCode` for original source projects; `ProfilePage` only for a true person-focused biography. Do not fabricate company registration, legal equity, funding or global deployment.
5. Add one correct `rel=canonical` for the **published** page. No speculative domains or paths.
6. Generate a sitemap **only** for real canonical published pages; optionally include an accurate `lastmod`; place it at a correct site-relative location and reference it in `robots.txt`.
7. Verify the relevant domain/URL property in Google Search Console with the owner-controlled Google account; submit sitemap with authorization, inspect priority URLs and record actual crawl/index decisions.
8. Audit 404s, noindex, duplicate canonicals, mobile rendering, structured data, and broken public project backlinks after every site release.
